# Fresh-fixture commissioning history

This is a development record for v0.40 through v0.94. It distinguishes semantic
engine outcomes from static-contract, infrastructure, and process failures. It
is not a scorecard and it is not an oracle for a future holdout.

## Reuse boundary

Failed and abandoned artifacts are development evidence. Engineers may inspect,
repair, diff, replay through static validators, and convert them into synthetic
regressions. Actor-isolation mistakes invalidate an independence claim, not the
technical information in the artifact. Replace the actor when independence is
still needed; otherwise retain the work as ordinary development data.

Freshness applies at final qualification. A final holdout must use new source,
pass spent-lineage isolation, and remain unseen by the engine and implementers
until its one authorized execution. A prior fixture that has been opened,
executed, or used for implementation is no longer fresh, but it remains useful.

Promoted regressions must assert a general contract with newly written minimal
source. Do not key product behavior to a historical release ID, probe ID,
sentence, byte range, or expected output.

## Changes promoted to shared code

The audit produced shared primitives rather than more one-off card prose:

- `authoredScenarioRawPayload` defines non-self-referential source lineage.
- `authoredCursorSourceAnchor` projects cursor input to the exact anchor shape.
- `sortAuthoredAnchors` canonicalizes navigation by resolved source key.
- `sortFreshBlindAuthoringSelectors` canonicalizes complete safety selectors.
- `freshBlindWholeSecondTimestamp` emits the timestamp accepted by both public
  parsers.
- `assertSameCanonicalPath` compares filesystem identities across path aliases.
- The workflow proves the permanent reservation once in an authenticated step;
  engine execution and failure terminalization use local identity checks and do
  not depend on GitHub availability.

The [spent holdout postmortems](spent-holdout-postmortems.md) retain detailed
semantic findings for executed fixtures. This ledger also records the many
commissioning attempts that never became engine results.
