# Semath

Semath is an embeddable Rust/WASM semantic engine for mathematical and
engineering Markdown and LaTeX. It provides navigation, analysis, diagnostics,
and reviewable refactoring primitives to hosts such as CorTeX; it is not a
standalone web application.

Start with the [documentation index](docs/index.md). Current work is tracked in
[GitHub issues](https://github.com/corca-ai/semath/issues).

Coding agents should follow the compact [project agent guide](AGENTS.md).
