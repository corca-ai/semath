# Semath

Semath is a conservative Rust/WASM analyzer for mathematical Markdown and
LaTeX. It tracks explicit definitions, checks grounded type and dimension
constraints, and provides reviewable edits to hosts such as CorTeX.
Missing evidence stays unknown; Semath does not infer arbitrary author intent.

Start with the [documentation index](docs/index.md). Current work is tracked in
[GitHub issues](https://github.com/corca-ai/semath/issues).

Coding agents should follow the compact [project agent guide](AGENTS.md).
